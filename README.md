# Yi Han Software Engineering Portfolio

This repository contains Yi Han's role-specific software engineering portfolio:

https://hannnnnnnny.github.io/yi-han-software-engineer/

It is a static GitHub Pages site focused on full-stack software projects, with a small vanilla JavaScript layer for the command palette, project filters, skill map, scroll state, and system-flow canvas.

## Featured Projects

- ReNova Second-Hand C2C Marketplace
- KiwiCue
- TillTally

## Structure

- `index.html` contains the page content.
- `styles.css` contains the layout and visual styling.
- `app.js` contains the progressive interactions.
- `assets/` contains shared resume and preview assets.
- `.nojekyll` keeps GitHub Pages from running Jekyll.

## Local Preview

Open `index.html` directly in a browser, or serve the folder with a static file server.

No build step is required.
